# UI Pass 1: Refresh in the Explorer, visible workspace, prominent agent bar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Act on the user's feedback after Milestone 5: the Refresh action lives with the file tree it reloads; the currently open workspace (name, branch, repo) is always obvious; the group/agent bar reads unmistakably as "your agents" even with one workspace.

**Architecture:** C++-only layout changes over the existing Rust models. `ExplorerDock` gains a header strip fed by the active tab's JSON (name, branch, repo) with the Refresh button; `MainWindow` drops the toolbar and sets the window title from the same data; `GroupBar` gets a labelled, taller agent row with status dots, name + branch per tab, a text "New agent" button and an inline empty state. No decision moves into C++: every label comes from `GroupModel`'s JSON.

**Tech Stack:** Qt 6.9.2 Widgets, cxx-qt 0.10 (no bridge changes expected).

**Spec:** IDE spec §2 (layout), §3 (`GroupBar`, `ExplorerDock`, `MainWindow`); user feedback memory `ui-feedback-2026-09-10`.

## Global Constraints

- C++ paints and forwards only; labels and status come from `GroupModel`/`activeTabJson` (`name`, `branch`, `repo_path`, `agent_status`, `adapter`). No new Rust state.
- Non-ASCII glyphs as code points (`QChar(0x25CF)` etc.), never in narrow literals.
- Theme-aware colours through `Theme.h`; status colours stay the ones `GroupBar::statusColour` uses today.
- No desktop input injection; verification via an env-gated in-process hook (removed before commit) and own-window `QWidget::grab()`; the user's live workspace `ws_eebdd832` is never touched — the hook creates its own throwaway workspaces and asserts their ids before every action.
- Gates: build with zero MSVC `warning C`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all -- --check`, `cargo test -p bondsymphonic-ide` (the offscreen smoke test runs the C++).
- Commit trailers: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01DcYV4WREYNvdE2MsWATepg`.

### Task 1: Explorer header with Refresh; window title; prominent agent bar

**Files:**
- Modify: `crates/ide/cpp/ExplorerDock.{h,cpp}`, `crates/ide/cpp/GroupBar.{h,cpp}`, `crates/ide/cpp/MainWindow.{h,cpp}`, `crates/ide/cpp/Theme.h` (a wash for the header/bar background if none fits)

**Interfaces:**
- `ExplorerDock::setWorkspaceHeader(const QString& name, const QString& branch, const QString& repoPath)` — the header strip above the Files/Changes tabs: line 1 bold `name`, line 2 `branch  ·  <last two path components of repoPath>` (full path in the tooltip); a `QToolButton` with `SP_BrowserReload` and tooltip "Reload the file tree and changes" on the right that calls `refresh()`; when no workspace is shown the strip says "No workspace selected" and the button is disabled. `setWorkspace(QString())` clears it.
- `MainWindow`: `buildToolBar()` and the "Main" toolbar are removed (Refresh now lives in the Explorer); `onActiveTabChanged` calls `m_explorer->setWorkspaceHeader(...)` from the active tab JSON and `setWindowTitle("<name> — <branch> — BondSymphonic")` (plain "BondSymphonic" with no active tab); the status bar keeps its branch label.
- `GroupBar`: a left-aligned caption row above the agent tabs reading "Agents" (small caps style label) with the group tabs on the same row to the right of it; agent tabs taller (stylesheet: padding 6 px 14 px, minimum height 32 px) with text `<dot> <name>  ·  <branch>` where `<dot>` is `QChar(0x25CF)` painted in the status colour and the tooltip remains repo/branch/adapter; the `+` becomes a `QToolButton` with text "New agent" and `SP_FileDialogNewFolder`-style icon, `Qt::ToolButtonTextBesideIcon`; when the displayed group has no tabs the agent row shows an inline label "No agents in this group yet" beside the button. The bar background takes a light `Theme.h` wash so it reads as a distinct band.
